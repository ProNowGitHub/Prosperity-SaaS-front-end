# Prosperity SaaS – Frontend

Vite app, deployed to Vercel on every push to `main`.

```bash
npm install
npm run dev     # http://localhost:5173
```

Set `VITE_API_URL` (Vercel project env var, or `.env.local` locally) to the backend URL.
Backend repo: https://github.com/ProNowGitHub/Prosperity-SaaS-back-end
